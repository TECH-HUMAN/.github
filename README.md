# Tech Human — organização no GitHub

Este repositório reúne a apresentação pública e as orientações gerais de colaboração da organização **TECH-HUMAN**. O [perfil institucional](profile/README.md) explica os papéis da Tech Human, Trustyu.ai e NEEDYU.

## Para quem está chegando

1. Leia o README do projeto escolhido para entender sua finalidade, estado e fonte canônica.
2. Confira as instruções locais (`CONTRIBUTING.md`, `AGENTS.md`, `CLAUDE.md` ou runbook, quando presentes).
3. Solicite ao responsável o acesso ao repositório e aos ambientes necessários. Participar da organização não implica acesso a todos os projetos.
4. Registre mudanças em PR com objetivo e verificações. Issues e responsáveis devem refletir o trabalho real.

## Estrutura deste repositório

| Diretório / arquivo | Conteúdo |
|---|---|
| `profile/` | Perfil da organização e ativos institucionais; o SVG antigo está identificado como histórico |
| `docs/` | Contexto do alinhamento institucional público |
| `scripts/` | Geração de ativos do perfil |
| `.github/workflows/` | Automação de renderização de ativos |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Princípios comuns de colaboração |
| [docs/README-TEMPLATE.md](docs/README-TEMPLATE.md) | Modelo adaptável para apresentação dos projetos |

Descrições devem explicar o papel concreto do repositório. Topics devem indicar domínio e tecnologias presentes; o tópico comum é `tech-human`. O prefixo `techhuman-` é a referência para novos repositórios da marca, preservando identidades de produtos e integrações existentes. Renomeações precisam considerar links, clones e automações.
